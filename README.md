## Descripción

Este repositorio contiene la solución a la Práctica 2 del curso de Organización de Computadores, correspondiente al desarrollo de programas en lenguaje ensamblador Hack y la construcción de los componentes principales de la arquitectura Hack (Memory, CPU y Computer), utilizando el Hardware Description Language (HDL) de la plataforma Nand2Tetris.
